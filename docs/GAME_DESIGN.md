# （旧）〜5億6490万を超えろ〜 企画書

## コンセプト
2009年9月28日の伝説の12時間ローンチを、本人にもう一度プレイさせる。
**「17年前の自分と現在の自分を戦わせるゲーム」**。
マーケティングを教えるゲームには絶対にしない（本人には簡単すぎる）。

- 用途: 村上宗嗣さん本人へのプレゼント。一般公開しない
- プレイ時間: 設計20分＝実プレイ30分
- 形式: HTML/JS一枚もの（俺のサウナ方式）。iPhone/Macどちらでも動く。URLひとつで渡せる
- 事実の扱い: docs/FACTS.md に裏取り済みの事実のみ使用。捏造エピソード禁止

## ゲームの核
**状況を見る → 3〜4択から決断する → 売上が動く。** 操作はこれだけ。

- 選択肢の8割は本人なら即答できる問題 =「あー、これは分かってる（笑）」の快感。
  正解の根拠はすべて本人の公言している哲学（聞く姿勢／顧客リサーチ／煽らない／量を書く）
- 2割はギャグ（昼飯イベント等）
- 本気で迷う問題は終盤の「最終メール」だけ。ここは序盤で集めた隠しステータス
  「顧客理解」で正解が変わる
- 中盤から「史実との差 −¥31,200,000」を表示 → お客さんモードから本気モードへ切り替えるスイッチ

## ステータス（壁打ち1回目でSCRIPT.mdと一本化）
- 売上（メイン。常時カウンター表示。経済仕様はSCRIPT.md「経済仕様」節が正）
- 隠し5種: 顧客理解（E11の正解を決める）／信用（正負別変数・相殺不能）／思いやり／
  失敗（NEW MEMORY解放と連動）／へそ曲がり
- 史実ペース（正午から表示。時刻ごとの史実想定ラインとの差分）
- 表示のみの小ネタ（内部変数なし）: 体力・コピー力・ストーリー力・恥（リザルト固定ギャグ）
- 村上宗嗣度: **常時100%固定**（演出。変動させない）

## エンディング
- 史実超え: 「**村上宗嗣、17年ぶりに村上宗嗣を倒す。**」
- 届かず: 「**2009年の村上宗嗣、強すぎ。**」（負けても面白い設計）
- どちらでもエピローグへ:
  売上の記録→「売上」の文字が消え、お金/事業/仲間/自由/楽しいことが並ぶ→
  「あれから17年。あなたが次に増やしたいものは？」（どれを選んでも正解）→
  GAME CLEAR「次は何して遊びますか？」

## 演出方針
- ローンチ本編はイベント駆動（待ち時間ゼロ）。選択→数字ジャンプの交互打ち
- 売上カウンターは常時右上。跳ねる瞬間はカウントアップアニメ＋効果音
- 12:00→18:00の時計表示で「12時間を30分で生きる」体感を作る
- ビジュアルはドット絵（/dot-art量産。古いノートPC・オフィス・サーバールーム等）
- 数字は全編で算用数字に統一（壁打ち2回目: 台本実態に合わせ漢数字方針を撤回）
