# 村上宗嗣 事実集（公開情報・裏取り済み）

ゲームに使ってよいのはこのファイルに載っている事実だけ。
ここにない「エピソード風の創作」を本編に混ぜるのは禁止（本人に見せるゲームのため、捏造が一番冷める）。
演出上の脚色（スタッフのセリフ等）は「架空であることが明らかな形」でのみ可。

## 確定事実（複数ソース一致）

### 12時間ローンチ（ゲーム本編の舞台）
- 日付: **2009年9月28日**
- 内容: 「**継承プログラム**」の動画プロモーション
- 共同: **伊勢隆一郎（いせ りゅういちろう）氏**と共同で実施
- 時間帯: **午前6時〜午後6時の12時間**
- 売上: **約5億6,490万円**
- 時代背景: 当時は『情報ビジネスの終焉』が常識と言われていた
- 出典: 伊藤UN掲載の略歴PDF（ito-un.com/pdf/kurozu-ryakureki.pdf）ほか複数ブログ一致

### 前史（プロローグ素材）
- **元ヤクザ**。チンピラの子分として働き、睡眠は一日3時間程度、携帯が鳴ればいつでも出る生活
  - 一文でまとまった表現:「元ヤクザ、借金800万円以上、自殺未遂繰り返しの状態から、起業6年目には、
    わずか12時間のセールスで5億6490万円を売り上げ世界一の記録を達成し経済界に名を知られる存在となり、
    今はエンジェル投資家 兼 147億円のグループ会社のオーナー」（yaaaaaaachi.com）
- 重度のうつ病、借金800万円、自殺未遂を繰り返すドン底生活
- ネットビジネス参入から**7ヶ月で年収1,000万円**
- 「低学歴遅咲き27歳で最底辺から這い上がり」（本人Podcastプロフィール表現）
- 2007年7月、友人2人で立ち上げた会社が初年度売上8,900万円

### 人物像・哲学（選択肢の「正解」の根拠にする）
- 名言: 「**僕にコピーライティングの才能やセンスがあったかどうかは分からないですが、間違いなく言えることは世界一書いてきた。それは断言して言えます。**」
- 『聞く』姿勢を最も大切にする。相手への『共感』『感謝』『尊敬』『謙虚』
- 顧客が必要なもの・困っていることをリサーチし、欲しいものを提供する考え方
- 小学生やお年寄りにも分かる教え方に定評

### その後〜現在（エピローグ素材）
- 2011年3月11日 東日本大震災: 被災地で要望を聞き取り調査→ガイガーカウンター導入の便利屋ビジネス→600万円→最終的に億超え
- 手がけたビジネスは100超。株式会社essEnce代表、十数社の会社オーナー
- 2014年9月1日 株式会社地球人 設立
- 2025年現在（Podcastプロフィール）: **300社以上へのエンジェル投資**、**グループ年商156億円**、養護施設や非営利団体の複数の理事
- Podcast「**嫌でも元気になるラジオby村上むねつぐ**」
- モットー: 「**要は、楽しいことだけやる**」
- 願い: 「**毎朝起きるのが楽しみで仕方がない！と地球人全員が思える世界になるために**」幸せホルモン・オキシトシンを配達中

## 未確認・使用注意
- 「27歳でネットビジネス開始」の正確な年齢と年の対応は一次確認できていない → 年齢は「27歳、最底辺」というプロフィール表現の引用に留める
- 継承プログラムの価格・購入者数 → ゲーム内では数字を出さない（売上総額のみ使う）
- 当時のスタッフ・チーム構成 → 不明。ゲーム内スタッフは架空の「スタッフ」「エンジニア」とし、実名を与えない
- 伊勢隆一郎氏は実在の共同プロモーターなので登場させてよいが、セリフは創作と分かる範囲で敬意を持って扱う
