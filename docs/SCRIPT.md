# 『村上宗嗣の12時間』 台本 v5 — 12通のメルマガで継承を売る

**旧v4（13イベント版）は全面差し替え。** 核は「顧客の声を読んで、次の一通で何を伝えるかを決める」。
コピーライティングを教えるゲームにしない。本人に**もう一度「継承」を売ってもらう**ゲーム。

最重要KPI: 村上宗嗣さん本人が30分遊んで「楽しい」「よく調べて作ってる」と思うこと。
表のクリア条件=史実 ¥564,900,000 超え／**裏の条件=リストを焼かずに超える**。

---

## 0. 事実の扱い（v5で更新）

- **借金は「400万円以上」で確定**（作者決定。公式略歴の「800万円」とは食い違うが、
  継承当時の文脈は作者判断を優先する。ゲーム内の全記述をこれに統一）
- **「ゲームは悪い」は携帯ゲーム・ソシャゲ限定の発言**。丸めない。本人は「2日寝ないで
  ゲームしても平気」なゲーマーなので、限定を残したほうが正確かつオチが強い
- 継承の**販売価格は公表情報にない**。ゲームは客単価を内部に持つが**画面に出さない**
  （売上と購入者数のみ表示。分割/一括の混在という設定で単価を曖昧にする）
- 事実タグは3種を継続:「※実話です」「※別の日の実話です」「※本人の習慣です」。
  **結果画面でのみ表示**（選択肢面に出すと正解マーカーになる）

## 2. メイン画面（常時表示）

```
6:00                                    ♪
売上          ¥0
史実まで      あと ¥564,900,000
購入者              0人
見込み客       30,000人      解除 0人
```
- 解除が出た瞬間だけ**画面を赤くフラッシュ**し、見込み客の数字がカウントダウンする
- 「史実まで」は残り額。終盤で1000万円台に入ると金色に変わる

## 3. 1ラウンドの流れ（12回反復・1回90〜120秒）

1. **顧客の声**（前ラウンドの結果。購入者／未購入者／解除者から数件）
   ——これが次の一通のヒントになる。ゲーム性の中心
2. **本文の方針を4択**
3. **件名を4択**
4. 送信
5. **開封率が動く** → **売上カウンターが猛烈に増える** → **購入者が増える**
6. **少し遅れて解除が発生**（ここで演出の落差を作る）
7. 次の1時間へ

**制作上の最優先は 5→6 のテンポ。**「売れた！」→「……焼いた」の落差が本作の快感の芯。

## 4. 選択肢の4タイプ

| 型 | 性格 | 売上 | 解除 | 後半への影響 |
|---|---|---|---|---|
| **A** 村上らしい正解 | 顧客理解が深い。信頼を守る | ○〜◎ | 少 | プラス（信用・期待が積む） |
| **B** 強引だが売れる | 開封・短期売上は高い | ◎ | 多 | 見込み客を削る |
| **C** 凡打 | 間違いではないが弱い | △ | 少 | ほぼ無し |
| **D** 地雷 | 煽り／自己中／脅迫／不一致 | △〜◎ | 特大 | 致命的 |

**「正解だけ分かりやすい」を禁止する。** 4つとも「それっぽい」こと。特に件名は
**4つとも押したくなる**強さにする。本人向けなので一般ゲームより難しくてよい。

## 5. 件名 × 本文の整合性

独立採点しない。件名が約束したことを本文が裏切ると**釣り扱い**で解除が跳ねる。

各選択肢は `tone` を持つ:
- `honest`（正直・逆説・告白） / `hype`（煽り・限定・扇動） / `flat`（凡庸・説明的） / `ego`（自分語り・実績誇示）

判定:
- 同系 → 整合ボーナス（成約率＋、解除−）
- `honest`件名 × `hype`本文 → **釣り**（解除×2.2。「村上さんらしくない」の声が出る）
- `hype`件名 × `honest`本文 → 肩透かし（成約率−、解除微増）
- `ego`はどの組でも信用が下がる

## 6. 数値モデル（data.jsのCONF）

```
初期見込み客     30,000人
客単価           内部のみ。分割/一括の混在で ¥132,000〜¥168,000 相当（画面に出さない）
開封率  = 件名base(0.18〜0.42) × (1 + 刺激度×0.25) × (1 − 疲労×0.3)
成約率  = 本文base(0.004〜0.030) × 整合係数 × (1 + 顧客理解/100) × (1 + 信用/120) × 期待係数
解除率  = 型base × 整合係数 × (1 + 刺激度×0.6)
売上    = 開封 × 成約率 × 客単価
```
隠しパラメータ: **信用 / 顧客理解 / 期待 / 刺激度 / 気遣いポイント**
- 刺激度は煽るほど上がる。上げると開封率は上がるが解除も跳ね、後半に効いてくる
- 期待は「次のメールが読みたい」度。honest系の連打で積み、釣りで崩れる

**合格基準テスト（実装時に自動検査する）**
1. 全A ＋ 整合維持 → 最終売上 ≥ ¥565,000,000 かつ 解除 ≤ 1,200人（=Sランク到達可能）
2. 全B（強引ルート）→ 売上は ¥560,000,000 前後まで届くが解除 ≥ 6,000人 → **総合B以下**
3. 全D → 見込み客が終盤で枯れ、最終売上 ≤ ¥300,000,000
4. 全C → ¥380,000,000〜¥450,000,000（「間違ってないが届かない」）
5. どのルートでも見込み客が0未満にならない／解除が発行済みリストを超えない
6. 12ラウンド×(本文4×件名4)=192通りすべてに反応テキストが定義されている（フォールスルー0）

## 7. 12ラウンドの設計

各ラウンドの記法:
- **状況** = ラウンド開始時に出る顧客の声（前ラウンドの結果で分岐する場合は併記）
- **本文4択** / **件名4択** に型と tone を付す

### R1（6:00）販売開始 — 継承とは何か
**状況**: 見込み客30,000人。まだ誰も何も知らない。

**本文**
- A `honest` 借金400万円だった約3年前から、いまに至るまでを順番に話す
- B `hype` いきなり「人生を変える最後のチャンス」と宣言して煽る
- C `flat` 継承の教材構成とカリキュラムを順に説明する
- D `ego` 現在の実績（年収・会社・成功者の数）を並べて権威づける

**件名**
- A `honest` 「3年前、僕には400万円以上の借金がありました。」
- B `hype` 「人生を変える12時間が、いま始まりました。」
- C `flat` 「『継承』販売開始のお知らせ」
- D `ego` 「年収3000万円の僕が、すべてを公開します。」

**声（結果に応じて）**
- 購入「その借金の話で、なんか自分にもできる気がしました。」
- 未購入「興味はあります。でも自分にもできるのか不安です。」
- 解除「初っぱなから煽られている感じがして。」

---

### R2（7:00）様子見が多い — なぜ継承を作ったのか
**状況**: 未購入者「様子を見ています」「なぜ今これを売るんですか？」

**本文**
- A `honest` 自分の手の内を明かす理由を正直に話す（隠しても増えるものがない）
- B `hype` 「この価格で出すのは今日だけ」と希少性を強調する
- C `flat` 販売ページに書いたことをもう一度整理して伝える
- D `ego` 「教えてやる」という上からの姿勢で、選ばれた人だけに、と煽る

**件名**
- A `honest` 「なぜ、僕は自分の手の内を明かすのか。」
- B `hype` 「今日を逃すと、二度とありません。」
- C `flat` 「『継承』についてよくいただく質問。」
- D `ego` 「これを理解できる人だけ、読んでください。」

**声**
- 購入「理由が腑に落ちたので決めました。」
- 未購入「村上さんだからできたんじゃないですか？」 ← R3への引き
- 解除「限定・限定と急かされるのが苦手で。」

### R3（8:00）「村上だからできたのでは？」 — 特別な人間ではなかった
**状況**: 未購入者の声が明確に来ている。**ここが最初の"声を読む"問題。**

**本文**
- A `honest` 成功する前の失敗・借金・うつ・自殺未遂の手前まで、正直に語る
- B `hype` 「誰でもできる」と断言し、簡単さを強調する
- C `flat` 継承の教材量とサポート体制を説明する
- D `ego` いまの実績をさらに並べて「だから信じてほしい」と押す

（**Dは「声を読めていない」典型**。前ラウンドの疑問に実績で答えると火に油）

**件名**
- A `honest` 「僕は、特別な人間ではありません。」
- B `hype` 「誰でも、確実に、できます。」
- C `flat` 「継承で学べることの全体像。」
- D `ego` 「僕が年商を伸ばし続けられる理由。」

**声**
- 購入「同じところにいた人の話だと分かって、決めました。」
- 解除「『誰でもできる』は、さすがに信じられません。」

**本文**

**件名**

（**D注意**: 「世界一書いてきた」は本人の実言だが、**自慢として使うと地雷**になる設計。

**声**

### R5（10:00）価格への抵抗 — 価格ではなく、得られる変化
**本文**
- A `honest` 価格の話をせず、16週間後にどうなっているかを具体的に描く
- B `hype` 「今日中なら分割手数料を持ちます」と条件で押す

**件名**

**声**

### R6（11:00）売上鈍化 — 顧客の本当の不安を見抜く
**状況**: 開封はされている。**が、売れていない。**（＝価格でも情報量でもない）

**本文**
- A `honest` 買わない理由を**聞く**。返信を求め、答えると約束する
- B `hype` 「残りわずか」で締切を前倒しする
- C `flat` 特典を追加して価値を積む
- D `ego` 「もう十分説明しました」と匙を投げる素振りで揺さぶる

**件名**
- A `honest` 「まだ申し込まないでください。」
- B `hype` 「そろそろ、締め切ります。」
- C `flat` 「特典を追加しました。」
- D `ego` 「これ以上は、説明しません。」

（**件名A×本文Aが最大の整合ボーナス**。「まだ申し込まないで」と言って本当に引き止めない
 ＝本人の「買わなくても読んで得したと思ってほしい」思想の体現。
 逆に**件名A×本文B/Dは最悪の釣り**＝解除が跳ねる）

**声**
- 購入「引き止められなかったから、逆に決めました。」
- 未購入「16週間、続けられる自信がありません。」 ← R8への引き
- 解除「『まだ申し込まないで』と言いながら急かすんですね。」（釣り時のみ）

### R11（16:00）残り2時間 — 最後の不安を解消する
**状況**: **プレイヤーがここまでに集めた声によって、正解が変わる**（顧客理解の回収）。

**本文**（顧客理解が高いほど、正しい不安を選べる）
- A `honest` 「自分にできるのか」の不安に答える（R1・R3で拾った声）
- B `honest` 「価格」の不安に答える（R5で拾った声。**この時点では既に解けている＝空振り**）
- C `honest` 「続けられるか」の不安に答える（R8の声。**Aの次に効く**）
